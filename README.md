Hospital Database Project

Overview

A relational database project designed to manage hospital operations and organize information about patients, doctors, departments, appointments, and other hospital activities.

Objectives

- Practice SQL and relational database design.
- Define tables and relationships using primary and foreign keys.
- Apply SQL constraints to maintain data integrity.
- Write SQL queries to retrieve and analyze data.
- Practice joins, aggregate functions, subqueries, and other SQL concepts.

Database Contents

- Patients
- Doctors
- Departments
- Appointments
- Additional tables based on the project design

Technologies

- SQL
- SQL SERVER

Project Structure

SQL scripts are organized by their purpose, including database creation, table definitions, sample data, and queries.
